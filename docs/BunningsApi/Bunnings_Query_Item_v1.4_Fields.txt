BUNNINGS QUERY ITEM API v1.4 - FIELD NAME INDEX
==============================================
Source (official OpenAPI YAML):
https://developer.live.bunnings.com.au/sites/default/files/open-api-ref/Item.Query_.API_.v1_4.oas_.yaml

Scope: product DETAIL response fields and nested fields, then other Query Item responses.
These are POSSIBLE schema properties, not guaranteed to be present or usable for
every product/account/scope, and NOT necessarily supported as GoTradie template tags.
[] means an array; {key} means a dynamic metadata key.

NOTES
-----
- Item.enrichedData is the official OpenAPI field name for enhanced product information.
- The Item detail root brand field is a string; enrichedData.brand is a structured object.
- In the Bunnings API, costs under sourcing are Bunnings supplier costs, NOT customer retail prices.
- Search results have their own title field; the detail endpoint has other descriptions.
- This is a schema inventory, not a GoTradie implementation proposal.
